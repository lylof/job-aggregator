# 🔄 COMMENT METTRE À JOUR CE SYSTÈME

## 📝 POUR METTRE À JOUR L'ÉTAT DU PROJET (`project-state.md`)

1. Identifier les changements depuis la dernière mise à jour
2. Mettre à jour les métriques et composants
3. Ajuster les priorités si nécessaire
4. Noter la date de mise à jour

## 📜 POUR MODIFIER LES RÈGLES ESSENTIELLES (`essential-rules.md`)

1. Identifier pourquoi la règle actuelle est insuffisante
2. Proposer une amélioration spécifique
3. Vérifier que ça reste dans la limite de 7 règles
4. Mettre à jour le fichier avec justification

## 🔄 POUR AJOUTER UN TEMPLATE

1. Identifier un workflow répétitif
2. Créer un template simple et clair
3. Ajouter à `workflow-templates.md`
4. Tester le template avec un exemple réel

---
*Le système doit rester simple et facile à maintenir*
